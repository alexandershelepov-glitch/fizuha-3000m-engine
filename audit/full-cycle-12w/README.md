# Независимая проверка методики 3000 м: 12 недель × 6 пользователей

> **Всё в этой папке — синтетическое.** Отчёты о занятиях придуманы сценарием (A/Б/В/S), а не измерены. Контрольные и итоговые результаты 3000 м задаёт оператор сценария и **автоматически не улучшаются** (кроме отдельного набора S, где улучшение — явный сценарный ввод, а не прогноз). Это проверка методики по назначениям, а не доказательство тренировочного эффекта.

| Файл | Содержимое |
|---|---|
| `report.md` | Главный отчёт: сводная таблица по пользователям, проверка по типам занятий, реакция на отчёты, каталог недостатков (критические / методические / незначительные), заключение |
| `weekly-tables.md` | Таблицы по неделям для всех 23 сценариев: план км, факт км (синтетически), число занятий, число интенсивных, назначенные темпы, изменения нагрузки |
| `data/workouts.csv`, `data/workouts.json` | Все назначенные занятия: тип, доза, темп, км/ч, повторы, отдых, исход (синтетический), оценка, классификация пропусков чисел |
| `data/weekly.csv` | Недельные итоги |
| `data/findings.json` | Все находки без группировки |
| `data/events.csv` | Внешние/синтетические события (контрольные, подтверждение 3 км, снятие hold, итоговый забег) |
| `data/scenarios.json` | Сценарии, начальная оценка движка, результаты проверок |
| `raw/*.txt` | Сырые логи прогонов и тестов (имеют расширение `.txt`, т.к. `*.log` в `.gitignore`) |

## Как воспроизвести

Нужен Node ≥ 22.18.

```bash
npm ci
npm run audit:12w   # пересоздаёт report.md, weekly-tables.md и data/ (детерминированно)
node --experimental-strip-types --test tests/audit-12w.test.ts
```

Код: `audit/fullCycle12w.ts` (сценарии и драйвер; расширяет `audit/trainingSimulator.ts`, использует его `makeResult`/`healthySafety`/`SIM_START`), `audit/fullCycleAnalysis.ts` (проверки и находки), `audit/run12w.ts` (генератор отчёта), `tests/audit-12w.test.ts`.

## Что не менялось

Движок (`src/`), методика, веб-приложение и существующие 9 сценариев симулятора не изменены. Добавлены только сценарии, проверки, отчёты и инструменты.
