# Проверка симулятора «ФИЗУХА — 3000 м»

Дата адаптации: 13.10.2026. Основа: `main` после интеграции PR #14 (`acb21baa`).

Симулятор — независимый сценарный инструмент, не новый тренировочный движок. Запуск: `npm run audit:training`. Формирует `audit/reports/training-audit.md` и `.json` в CI-артефактах.

Старые находки от 12.10 сохранены как `audit/archived-findings-2026-10-12.md` и не должны выдаваться за текущее состояние. Противоречивый отчёт теперь должен отклоняться `RESULT_DISTANCE_CONFLICT`; после этого в сценарии отдельно вводится исправленный гипотетический результат.

**Успех автоматических тестов не доказывает безопасную нагрузку и достижение норматива в реальной жизни.** Не завершены отдельная лестница RUN_WALK при <5 км/нед., интерфейс подтверждения непрерывных 3 км и полный контроль недельной нагрузки при интенсивных упражнениях, заданных по времени. Отчёт о фактических новых сценариях получается из текущего CI, а не копированием чисел из архива.
