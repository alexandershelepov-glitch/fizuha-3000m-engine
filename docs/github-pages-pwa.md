# Публикация ФИЗУХА — 3000 м на GitHub Pages

Репозиторий: alexandershelepov-glitch/fizuha-3000m-engine
Стандартный адрес проекта после публикации:
https://alexandershelepov-glitch.github.io/fizuha-3000m-engine/

## Один раз в настройках GitHub

1. Откройте Settings → Pages этого репозитория.
2. В разделе Build and deployment укажите Source = GitHub Actions.
3. Перейдите на Actions → Publish Fizuha PWA → Run workflow (main).

Если раздел Pages не разрешает публикацию, проверьте тариф GitHub:
для **приватного** репозитория необходим GitHub Pro/Team/Enterprise.
На GitHub Free Pages доступен при публичном репозитории.
Не меняйте приватность кода без отдельного решения владельца.

После включения Pages новые коммиты main автоматически собирают и публикуют PWA.
До включения Pages workflow всегда готовит пакет, а deploy пропускается.

## Технические гарантии пакета

- Vite production base: /fizuha-3000m-engine/; local dev base: /.
- Маршруты поддерживают prefixed URLs; 404.html повторяет index.html для SPA
  (GitHub Pages отдаёт глубокие ссылки со статусом HTTP 404 до регистрации SW).
- Манифест PWA использует относительные start_url/scope/icons.
- Service worker регистрируется лишь внутри папки проекта; при установке
  скачивает index, JS/CSS и иконки. Кэш сбрасывается по версии коммита.
- Каждый deploy-пакет проверяется на правильные URLs и существование иконок.
- Training engine, localStorage and user reports не отправляются на сервер.

## Проверка на телефоне

1. Откройте опубликованный URL (не URL репозитория) в Safari/Chrome.
2. Заполните тестовую анкету, откройте тренировку, перезагрузите страницу.
3. Откройте прямую ссылку на раздел План в новой вкладке.
4. Установите PWA через меню браузера «На экран Домой» (iPhone: Safari → Поделиться).
5. Откройте приложение с главного экрана, убедитесь в сохранении плана.
6. После первого успешного открытия и установки выключите интернет:
   главная страница и сохранённые данные должны открываться.

Данные сохраняются в localStorage **только этого браузера/устройства**:
нет синхронизации между телефоном и компьютером, резервное копирование пока
не реализовано. Удаление данных браузера или PWA может удалить тренировочный цикл.

## Команды проверки

- Корневая сборка: npm run build:web
- Сборка для Pages:
  PWA_BASE=/fizuha-3000m-engine/ npm run build:web
  PWA_BASE=/fizuha-3000m-engine/ node scripts/prepare-pages.mjs

GitHub Actions PWA regression checks проводит обе проверки без публикации.
