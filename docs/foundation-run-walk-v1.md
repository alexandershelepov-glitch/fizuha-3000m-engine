# ФИЗУХА — вводный бег с ходьбой (проверяемая реализация)

Дата 13.10.2026. Задача: понятные и постепенно усложняющиеся занятия для пользователя, **не способного пока пробежать 3000 м непрерывно** (`canRun3Km=false`).

## Пользователь видит

В каждом EASY/RUN_WALK задана однозначная пара «бег X секунд → ходьба Y секунд». Повторять до указанной **суммарной дистанции бега с ходьбой**; последние отрезки можно сократить. Перед основной частью 5 минут ходьбы для разминки; после 5 минут для заминки. Медленный бег с возможностью разговаривать, плановое усилие 2–4 из 10. Числовой темп не выдумывается.

12 ступеней (секунды бега / ходьбы): 30/120, 45/120, 60/120, 90/120, 120/120, 180/90, 240/90, 300/60, 480/60, 600/60, 900/60, 1200/60. Это **пилотная последовательность**, а не гарантированный срок перехода к 3000 м. Конкретная пара хранится в назначении; приложение отображает именно её.

## Когда растёт нагрузка

Движок пересматривает прошедшие **14 полных дней**. Все назначенные сессии блока должны быть выполнены, с явно подтверждёнными выполнением, нагрузкой и самочувствием, получить GREEN/GREEN_PLUS. Любая болезнь, боль, RED/YELLOW, пропуск, старый неподтверждённый отчёт, перерыв, медицинская остановка, taper, недостоверность или невозможность выполнить все занятия **не дают прибавки**. Открытие приложения через несколько недель не выдаёт задолженные ступени.

Подтверждённые блоки чередуются: один блок увеличивает **длительность беговых отрезков**, следующий (при успехе) — **суммарную недельную дистанцию**. Обе величины в одном блоке не увеличиваются. Прежний лимит **количества тренировок в неделю** не повышается автоматически. Вклад ходьбы включён в консервативно ограниченный метраж RUN_WALK; нет пересчёта метров в секунды по выдуманной скорости.

У исторического объёма 0–4,999 км/нед.: начальный разрешённый метраж 1 км/7 дней при 0; затем в дистанционном блоке не более 10% **текущего разрешённого метража**, максимум +200 м и округление вниз до 50 м. Это проектное ограничение консервативного роста, **не универсально доказанная медицинская норма**. При >=5 км/нед. дистанционный блок может добавлять +500 м. Если ступени закончились, продолжение выполняется без автоматического подтверждения готовности к 3000 м.

## Достоверность и безопасность

`canRun3Km` и время 3000 м **не изменяются** от тренировочных GREEN. Для подтверждения способности пробежать 3000 м без остановки нужен отдельный осознанный пользовательский шаг, предусмотренный следующим этапом. Даже успешное выполнение последней ступени не означает медицинского допуска, спортивного результата или подтверждённой способности пробежать 3 км.

Старые сохранённые тренировки сохраняются без подмены заданий; старые циклы получают нулевую ступень **без ретроактивного начисления**. Изменения встраиваются в текущие `src/engine.ts` / `src/workouts.ts` без нового независимого планировщика.

## Границы

Непрерывный бег 3 км пока не проверяется приложением; ступень лишь готовит к нему. Переход из `canRun3Km=false` требует самостоятельного подтверждения. Суммарная километровая нагрузка интенсивной работы (особенно заданной минутами) всё ещё требует отдельной проверки. Спортивная пригодность проверяется будущим пилотом с реальными отчётами работников.
