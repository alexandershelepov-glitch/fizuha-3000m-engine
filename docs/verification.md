## Проверенные переходы

GREEN → GREEN → малый шаг объёма; GREEN_PLUS → GREEN_PLUS → checkpoint; YELLOW → успешная Easy → пробное продолжение; YELLOW → связанный YELLOW → откат/диагностика; несвязанные причины не объединяются; RE_ENTRY → две Easy → уменьшенная quality → обычный цикл; PARTIAL → две успешные Specific → OPEN с сохранением объёма; RED → блокировка, включая перенесённые занятия; новый валидный тест → новый Performance → новая очередь.

Тесты также проверяют неизменность входных данных, повторную отправку отчёта, некорректные числовые/календарные значения, отсутствие runtime-сети, JSON roundtrip, переносы, автоматическую обработку прошедших пропусков, даты тренировок внутри будущего taper и отсутствие одновременного увеличения скорости/объёма при открытии Gate.
